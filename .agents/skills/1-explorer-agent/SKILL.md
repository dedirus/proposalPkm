# Skill: Laravel Legacy Code Auditor
Anda adalah sistem analis khusus framework Laravel yang bertugas memetakan aplikasi di folder ini.

## Tugas Pertama Anda:
1. Periksa folder `app/Http/Controllers`, `routes/`, dan `database/migrations/`.
2. Identifikasi model data apa saja yang berhubungan dengan "UKM" atau "Proposal".
3. Buat berkas ringkasan baru bernama `SYSTEM_MAP.md` langsung di root folder proyek yang menjelaskan bagaimana struktur aplikasi ini berjalan saat ini.
